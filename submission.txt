SUBMISSION PEMDA - ETL PIPELINE PROJECT

========================================
1. CARA MENJALANKAN SCRIPT ETL PIPELINE
========================================

Langkah-langkah:

a. Aktifkan Virtual Environment:
   Jalankan perintah berikut:
   .venv\Scripts\Activate.ps1

b. Pasang Dependency (jika belum):
   pip install -r requirements.txt

c. Jalankan ETL Pipeline:
   python main.py

   Skrip ini akan:
   - Extract data produk dari https://fashion-studio.dicoding.dev/
   - Transform data (validasi, normalisasi, konversi, hapus duplikat)
   - Load hasil ke file CSV (products.csv)

========================================
2. CARA MENJALANKAN UNIT TEST
========================================

Langkah-langkah:

a. Pastikan virtual environment sudah aktif

b. Jalankan semua unit test:
   pytest

   Atau jalankan test file spesifik:
   - pytest tests/test_extract.py
   - pytest tests/test_transform.py
   - pytest tests/test_load.py

   Atau dengan verbose mode untuk detail lebih lengkap:
   pytest -v

========================================
3. CARA MENJALANKAN TEST COVERAGE
========================================

Langkah-langkah:

a. Pastikan virtual environment sudah aktif

b. Instal pytest-cov (jika belum):
   pip install pytest-cov

c. Jalankan test coverage:
   pytest --cov=utils --cov-report=html

   Atau untuk report di terminal:
   pytest --cov=utils --cov-report=term-missing

d. Hasil coverage dapat dilihat di:
   - Terminal (jika menggunakan term-missing)
   - Folder htmlcov/ (jika menggunakan html report)
